# Apply confirmed doc edits

1. Open the owner-queue's Doc edits section. Take only items marked `confirmed`. Leave `WAITING` items alone.
2. Use the quoted wording **as written**. Do not paraphrase: paraphrasing the owner's wording is how rules drift.
3. Put each edit where the item says. Tick or remove the item.
4. Do nothing else: no code, no tests, no fixes. If something looks wrong, report it (what, where, a suggested fix).
